{ 整体规范综述 }

INTRODUCTION

整体规范综述：商品信息围绕用户选购需求，通过优化产品主图、标题、卖点、参数楼层&属性和图文详情等7项基础内容，优化用户体验，提升转化率。

  • 【主图】

    主图规范采用模块化布局，将画面划分为5个模块，帮助用户在短时间内捕捉关键信息，提升点击意愿与信息吸收效率

  • 【主图视频】

    主图视频建议聚焦产品，以高科技视觉呈现核心优势；围绕“节能、安全、静音”，用对比、模拟、展示等方式突出四大核心优势

  • 【长标题】

    优先保证汽机油系列、机油类型、粘度、等级、容量等关键信息完整展示，便于消费者快速识别产品核心参数与适用车型

  • 【短标题】

    优先突出“系列”和“核心参数”两大核心识别要素，核心参数包括粘度、机油类型、品质、容量，从而提升搜索点击率

  • 【卖点】

    根据机油规格类型动态选择强化心智，如包安装、系列升级、正品直供、性价比之选，目的是让用户直观感知产品优势，降低认知成本，提升点击与购买决策效率

  • 【属性】

    将汽机油关键参数信息从商详页最下方的属性模块上提至“参数楼层”，建议商家将高搜索、低填写的属性值填写完整，所有属性值须严格遵循规范填写，确保数据准确、一致，提升用户获取信息的效率和准确性

  • 【图文详情】

    通过结构化的图文详情设计，将汽机油的技术参数转化为用户可理解的决策信息，利用从活动引流到知识科普的逻辑闭环，降低用户选择难度并建立信任，从而提升购买转化率

{ 主图视频（建议方向） }

INTRODUCTION
核心原则：
  • 以用户为中心，通过动态视觉讲好汽机油故事，构建信任，高效转化。在有限时长内，精准传递产品价值，解决消费者痛点，促成购买决策。
详细要求：
  • 基础规格：视频时长控制在15-60秒，保证画面清晰稳定；整体比例、字幕大小都适配移动端观看，字幕不遮挡产品主体，手机端浏览清晰舒适。
  • 内容要求：开篇快速抓取用户注意力，突出核心卖点；内容紧扣消费者买机油最关心的粘度、机油等级、舒适静音、耐磨耐用、性价比等核心需求，精准戳点降低决策门槛。
  • 呈现规范：用简洁醒目的文字在画面中标注关键信息、核心卖点和技术参数；背景音乐选择符合产品定位、节奏适配的BGM，不遮挡语音信息，提升整体观看体验。

长标题结构公示为：
  • [品牌/中英文] + [系列] + [机油类型] + [黏度] + [机油标准] + [容量] + [卖点]/[服务承诺+保障]+汽车保养+适配车型
  • 1、“商品品牌”（不计总字符数），需与商品挂靠品牌一致。
  • 2、填核心描述（计入总字符数，≤60字符）。字符计算：1汉字/全角符号=2字符；1英文字母/半角符号/数字=1字符。
补充规则
  • 字符超限处理：若超过60，优先删除服务承诺/非核心卖点，确保基础信息完整，后半段命中词不使用空格；
  • 简称：系列仅需要写简称；

{ 短标题（点击率提升+8.1%） }

INTRODUCTION
短标题结构规范：
  • 品牌 + 系列名称 + 核心参数（粘度+机油类型+品质+容量） + 系列特点/卖点（非必填）
  • 字数要求：整个标题控制在8-15个汉字（30个字符内），1个英文字母/数字/符号 = 1字符
  • 核心规格参数：黏度、机油种类、品质、容量
  • 系列特点：短标中注明该系列特色，或者在短标题下注明系列特色如减少油耗、减震降噪、经济耐磨、环保低排放、适配广泛
  • 短标卖点：根据机油规格类型动态选择强化心智，如包安装、系列升级、正品直供、性价比之选

{ 卖点（点击率提升+8.1%） }

INTRODUCTION
核心原则：
  • 卖点需以消费者语言描述，突出直观价值，避免工业化术语。
详细建议：
  • 短标下方灰色字体，作为辅助信息，3个卖点，每个字数4-5个字，根据机油规格类型动态选择强化心智。语言上要使用场景化、易懂的词汇，强调体验、性价比、正品心智等。
卖点示例组合： （无优先级）
  • ①经济实用 | 减震降噪 | 持久润滑
  • ②经济抗磨 | 环保低排放 | 低温流畅
  • ③减少油耗 | 高温保护 | 恒久动力
